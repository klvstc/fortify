## Why Fortify?

Changing an unwanted habit is more than counting days. It is about understanding your triggers, staying consistent, and having something constructive to turn to when motivation fades.

**Fortify** brings a collection of habit-building tools into one experience: track daily streaks, check in with yourself, journal openly, explore AI-generated reflections, and celebrate your progress with milestones and rewards.

## Core Features

| Feature | What it offers |
| --- | --- |
| **Streaks & milestones** | Track consistency and celebrate meaningful checkpoints along your journey. |
| **S.O.S. access** | A prominently placed shortcut designed for moments when you need immediate support. |
| **Sanctuary & daily journaling** | Record thoughts, moods, and urges in a dedicated reflection space. |
| **AI-powered insights** | Explore personalized reflections and weekly reviews based on journal activity. |
| **Personal AI mentor** | Chat with a selectable mentor persona for encouragement and perspective. |
| **Aether rewards** | Earn in-app points through activities and work toward rewards and achievements. |
| **Recovery journey visuals** | See motivational illustrations of habit-change progress and personal milestones. |

## Technology

- **Android application:** Android project in `Android/`.
- **Web/frontend:** React, TypeScript, and Vite in `Fortify-Frontend/`.
- **AI integration:** Gemini-related service integration within the frontend project.
- **Design:** Dark-mode interface with progress visualization, journaling, and rewards.

## Getting Started

### Frontend

```bash
git clone https://github.com/klvstc/fortify.git
cd fortify/Fortify-Frontend
npm install
npm run dev
```

### Android

Open the `Android/` directory in **Android Studio**, let Gradle sync, and run the app using a supported emulator or device. Project-specific configuration may be required.

### Repository Layout

```text
fortify/
|-- Android/                  # Android application
|-- Fortify-Frontend/         # Web/frontend application
|-- assets/                   # README screenshots and visuals
`-- README.md
```

> **Security:** Do not commit API keys, service-account JSON credentials, or other secrets. Use environment-specific configuration or a secret manager. Revoke and rotate any credentials that were previously committed or exposed.
